Add the html2frame plugin to Figma

You do this once per computer. Afterwards the plugin stays under Plugins → Development, and the panel's captures come into Figma with one click.

  1. Install the Figma desktop app

    Download it from figma.com/downloads and sign in. Any plan works, the free one too. Figma in the browser can't load plugins from your computer, so it has to be the desktop app.

  2. Open a design file

    Open any Design file, or create one (+ Create → Design). The plugin menus only show inside a design file, not on the home screen or in FigJam and Slides.

  3. Import the plugin from its manifest

    Click the Figma menu (the Figma logo at the top left), then Plugins → Development → Import plugin from manifest…

    In the menu bar choose Plugins → Development → Import plugin from manifest…

    Shortcut: press Ctrl⌘ + /, type import plugin from manifest and press Enter.

    In the window that opens, choose this file:

    figma-plugin/manifest.json in the html2frame folder

    Tip: click Copy path, paste it into the File name box of Figma's window and press Enter.

    Tip: click Copy path, press ⌘ + Shift + G in Figma's window, paste the path and press Enter.

    Figma now lists html2frame under Plugins → Development.

  4. Run it

    Plugins → Development → html2frame, then Latest from panel (or Choose file for a capture file somebody sent you). Pick the screen sizes and variants, and click Import.

If something doesn't work

There is no “Development” menu, or “Import plugin from manifest…” is missing
You are in Figma in the browser, on the home screen, or in a FigJam or Slides file. Open a Design file in the desktop app.
“Latest from panel” says it can't reach the panel
This panel has to be running (keep its window open) at http://localhost:5600, the only address the plugin may load from. Or save the capture with Download JSON and use Choose file in the plugin.
You moved or renamed the html2frame folder
Figma remembers where the manifest was. Import it again from the new place (step 3).
You updated html2frame
Nothing to do: Figma loads the plugin from the folder each time you run it.
You want to remove the plugin
Plugins → Development → Manage plugins in development, then remove html2frame from the list.
