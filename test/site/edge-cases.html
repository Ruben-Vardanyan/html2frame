Known limits and tricky cases

Edge cases

Each card says what should appear in Figma today. “Not supported” cases document current limits; if one starts working, update its card.

Hidden elements

Visible line
display: none (must not appear)
visibility: hidden (must not appear)
opacity: 0 (must not appear)
Screen-reader only text
Second visible line
Expected: only the two visible lines. The 1px screen-reader text may appear as a tiny layer.

Pseudo-elements

::before dot
  1. First
  2. Second
Expected: the green dot. CSS counters (“1.”, “2.” from counter()) are not evaluated: they are missing.

List markers

  • Bullet one
  • Bullet two
  1. Number one
  2. Number two
Expected: bullets and numbers as text layers to the left of each item (markers are turned into text).

Paint order vs. z-index

z-index 2 (red, on top)
z-index 1 (blue)
Not supported: layers follow DOM order, so blue is drawn over red in Figma.

Transforms

Rotated −8°

Scaled 0.7
Expected: the orange box rotated −8° with its text, the blue box at 70 % size (text included). Rotation, scale and translate are kept; skew is not.

Text shadow, blend, filter

Text shadow mix-blend-mode filter: blur
Expected: an orange text shadow (drop shadow on the text layer), the blue box in Multiply blend mode, the green box with a layer blur. Other filters (brightness, grayscale…) have no Figma equivalent.

clip-path

Slanted by clip-path
Expected: the slanted shape, as a mask inside the frame; the text stays editable.

SVG <use> sprites

Expected: the red heart (symbol in this page) and the blue star (symbol in img/sprite.svg) as vectors.

Canvas, video, iframe

Expected: all three as images (a picture of each element taken at capture time; not editable).

Multi-column, vertical text

Text flowing over two CSS columns, long enough to need a second column for the rest of the sentence.
縦書き vertical
Expected: one text layer per column; the vertical text turned 90° clockwise (all glyphs turn, CJK included).

Animation and fixed

Animated (stopped)
Animations are switched off before capture: full opacity, no offset. The black “Fixed chip” sits at the bottom right of the first screen.

details / summary, hr

Open details

Content inside an open <details>.

Closed details

Hidden content.

Expected: open content visible, closed content hidden, a 1px line, and ▼ / ▶ triangles before the summaries.
